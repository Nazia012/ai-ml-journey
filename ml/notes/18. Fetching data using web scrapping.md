

### **1. What is Web Scraping & When to Use It?**

* **Definition:** Extracting structured data directly from the HTML source code of websites when no official API or downloadable dataset exists.
* **Core Python Stack:**
* `requests`: Sends an HTTP `GET` request to fetch the raw HTML text of a webpage.
* `BeautifulSoup` (`from bs4 import BeautifulSoup`): Parses the raw HTML into a navigable tree structure so you can extract specific tags, classes, and text.
* `pandas`: Organizes the scraped lists into a clean DataFrame and exports to `.csv`.



---

### **2. Handling Anti-Scraping Blocks (`403 Forbidden`)**

* Many websites block automated Python requests (`response.status_code == 403`) because they lack a browser's `User-Agent` header.
* **Fix:** Pass a standard browser `User-Agent` string inside a `headers` dictionary:
```python
import requests
from bs4 import BeautifulSoup

headers = {
    'User-Agent': 'Mozilla/5.0 (Windows NT 6.3; Win 64 ; x64) Apple WebKit /537.36(KHTML , like Gecko) Chrome/80.0.3987.162 Safari/537.36'
}
webpage = requests.get('https://www.ambitionbox.com/list-of-companies?page=1', headers=headers).text
soup = BeautifulSoup(webpage, 'lxml')

```


*(Note: `'lxml'` is the fast HTML/XML parser used under the hood by BeautifulSoup.)*

### **3. Step-by-Step Web Scraping Workflow (AmbitionBox Case Study)**

1. **Inspect the Webpage HTML Structure**
* Open the target site in Chrome, right-click the data you want (company name, rating, reviews, sector, headquarters, age, employee count), and click **Inspect**.
* Identify the repeating parent container tag (e.g., `<div class="company-content-wrapper">`) that holds each individual record/card on the page.


2. **Avoid Fragile Positional Indexing**
* If multiple fields share the exact same HTML tag and class (e.g., `<p class="infoEntity">` used for company type, headquarters, age, and employee size), relying purely on list indexing (`[0]`, `[1]`, `[2]`) can break if a company is missing one field—causing values to shift into the wrong columns.
* **Best Practice:** Loop over each parent **company card** (`for i in soup.find_all('div', class_='company-content-wrapper'):`) and extract fields inside each card safely using `try/except` blocks (appending `np.nan` when a field is missing).


3. **Extract Text Cleanly**
* Use `.find()` for a single element and `.find_all()` for a list of matching elements.
* Always attach `.text.strip()` to remove extra whitespace, newlines (`\n`), and tabs (`\t`) from the scraped HTML text.


4. **Scale Across Multiple Pages**
* Inspect how the URL changes when clicking **Next Page** (e.g., `?page=1`, `?page=2`, ... `?page=333`).
* Wrap the single-page scraping logic inside an outer loop `for j in range(1, total_pages + 1):`, build the page DataFrame, and combine all pages with `pd.concat(dfs, ignore_index=True)`.

### **4. Key BeautifulSoup Methods Cheatsheet**

| Method | What It Does | Example |
| --- | --- | --- |
| `soup.prettify()` | Formats raw HTML with readable indentation | `print(soup.prettify())` |
| `soup.find('tag', class_='...')` | Returns the **first** matching HTML element | `i.find('h2').text.strip()` |
| `soup.find_all('tag', class_='...')` | Returns a **list** of all matching HTML elements | `soup.find_all('div', class_='company-content-wrapper')` |
| `.text.strip()` | Extracts clean inner text without HTML tags or whitespace | `tag.text.strip()` |

### **5. Practical Best Practices**

* **Respect `robots.txt` & Rate Limits:** Check `[website.com/robots.txt](https://website.com/robots.txt)` to see which paths are disallowed, and add `time.sleep(1)` between page requests so you don't overload the server or get IP-banned.
* **Dynamic (JavaScript-Rendered) Sites:** `requests` + `BeautifulSoup` only works on static HTML. If content loads dynamically via JavaScript after page load, use **Selenium** or **Playwright** instead.
