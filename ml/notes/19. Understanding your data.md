### **Overview: Asking 7 Basic Questions When You First Get a Dataset**

Before jumping into Exploratory Data Analysis (EDA) or model building, run through these 7 fundamental checks in Pandas (demonstrated using the Titanic dataset) to build an accurate mental picture of your data.

---

### **1. How Big Is the Data?**

* **Method:** `df.shape`
* **Purpose:** Returns a tuple `(rows, columns)` showing the exact dimensions of the dataset.
* **Why It Matters:** Helps you anticipate memory usage, processing time, and whether you need chunking or sampling strategies upfront.

---

### **2. What Does the Data Look Like?**

* **Methods:** `df.head()` vs. `df.sample(5)`
* **Purpose:**
* `df.head()` displays the first 5 rows.
* `df.sample(5)` pulls 5 **random** rows from across the entire dataset.


* **Best Practice:** Prefer `df.sample(5)` over `df.head()`. Datasets are often sorted or grouped (e.g., all children or a single category at the top), so looking only at the first few rows can give a biased first impression.

---

### **3. What Are the Data Types of the Columns?**

* **Method:** `df.info()`
* **Purpose:** Displays every column's name, count of non-null values, data type (`int64`, `float64`, `object`), and total RAM usage.
* **Optimization Insight:** Spot numerical columns unnecessarily stored as `float64` (e.g., whole-number ages stored with decimals) that can be downcast to integers to save memory and speed up training on large datasets.

---

### **4. Are There Any Missing Values?**

* **Method:** `df.isnull().sum()`
* **Purpose:** Returns a Series showing the exact number of missing (`NaN`) values in each column.
* **Decision Insight:** Helps decide early on whether to impute (fill) missing values (e.g., `Age` with 177 missing values) or drop columns with excessive missing data (e.g., `Cabin` with 687 out of 891 missing values).

---

### **5. How Does the Data Look Mathematically?**

* **Method:** `df.describe()`
* **Purpose:** Generates high-level statistical summaries for all **numerical** columns: `count`, `mean`, `std` (standard deviation), `min`, `25%`, `50%` (median), `75%`, and `max`.
* **Why It Matters:** Quickly reveals data scale, spread, skewness, and potential anomalies/outliers (e.g., noticing extreme outliers in `Fare` or minimum `Age` values).

---

### **6. Are There Any Duplicate Rows?**

* **Method:** `df.duplicated().sum()`
* **Purpose:** Counts the total number of exact duplicate rows in the dataset.
* **Fix:** If duplicates exist (`> 0`), remove them using `df.drop_duplicates()` so repeated records don't bias your model.

---

### **7. How Is the Correlation Between Columns?**

* **Method:** `df.corr()` *(or `df.corr(numeric_only=True)` in newer Pandas versions)*
* **Purpose:** Computes the **Pearson correlation coefficient** (ranging from `-1` to `+1`) between numerical columns:
* **Close to `+1`:** Strong positive correlation (as one increases, the other increases—e.g., `Fare` vs. `Survived`).
* **Close to `-1`:** Strong negative/inverse correlation (as one increases, the other decreases—e.g., `Pclass` vs. `Survived`).
* **Close to `0`:** No linear relationship (e.g., `PassengerId` vs. `Survived`), signaling candidate columns to drop during feature selection.


* **Tip:** Isolate correlations with your target column directly using `df.corr(numeric_only=True)['Survived']`.

---

### **Quick Revision Cheatsheet**

| Question | Pandas Command |
| --- | --- |
| 1. Dataset dimensions? | `df.shape` |
| 2. Preview random rows? | `df.sample(5)` |
| 3. Column data types & memory? | `df.info()` |
| 4. Missing value counts? | `df.isnull().sum()` |
| 5. Statistical summary? | `df.describe()` |
| 6. Duplicate row count? | `df.duplicated().sum()` |
| 7. Feature correlations? | `df.corr(numeric_only=True)` |
