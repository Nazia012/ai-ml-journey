### **1. What is an API?**

* **Full Form:** Application Programming Interface.
* **Core Purpose:** Acts as a secure bridge (data pipeline) that allows two separate software applications or servers to communicate and exchange data without exposing their underlying databases directly.
* **Real-World Analogy:**
* Platforms like MakeMyTrip or Yatra do not own Indian Railways' database. Instead, they send requests to **IRCTC's API** with inputs (train number, date, class) and receive real-time seat availability in **JSON** format.
* Multi-platform apps (Web, Android, iOS) for services like Facebook all interact with a single central database through APIs.

### **2. Workflow: Creating a Dataset from a Paginated API (TMDB Case Study)**

1. **Get API Access & Inspect the Response**
* Register on the provider's developer portal (e.g., **TMDB — The Movie Database**) to generate a personal **API Key**.
* Test the endpoint URL in a browser or a tool like **JSON Viewer** to understand its structure:
* Top-level dictionary keys typically include `page`, `results` (a list of item dictionaries), `total_pages`, and `total_results`.


* Identify the exact fields (columns) you want to extract (e.g., `id`, `title`, `overview`, `release_date`, `popularity`, `vote_average`, `vote_count`).


2. **Fetch a Single Page in Python (`requests`)**
* Send an HTTP `GET` request to the API URL and convert the response into a Python dictionary using `.json()`:
```python
import pandas as pd
import requests

url = "https://api.themoviedb.org/3/movie/top_rated?api_key=YOUR_API_KEY&language=en-US&page=1"
response = requests.get(url)

# Status code 200 = Success | 404 = Not Found | 500 = Server Error
data = response.json()['results']
df = pd.DataFrame(data)[['id', 'title', 'overview', 'release_date', 'popularity', 'vote_average', 'vote_count']]

```




3. **Loop Across All Pages to Build the Full Dataset**
* Paginated APIs return a fixed number of records per page (e.g., 20 movies per page across 428 pages).
* Loop through every page number, inject it dynamically into the URL, and combine the DataFrames:
```python
dfs = []

for i in range(1, 429):
    url = f"https://api.themoviedb.org/3/movie/top_rated?api_key=YOUR_API_KEY&language=en-US&page={i}"
    response = requests.get(url)
    temp_df = pd.DataFrame(response.json()['results'])[
        ['id', 'title', 'overview', 'release_date', 'popularity', 'vote_average', 'vote_count']
    ]
    dfs.append(temp_df)

# Combine all page DataFrames cleanly with a continuous index
df = pd.concat(dfs, ignore_index=True)

```




*(Note: Modern Pandas uses `pd.concat(dfs, ignore_index=True)` instead of the deprecated `df.append()`.)*
4. **Export the Dataset to CSV**
* Save the compiled DataFrame locally for future ML projects or to publish on platforms like Kaggle:
```python
df.to_csv('movies.csv', index=False)

```
